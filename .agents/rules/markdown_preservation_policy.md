# Markdown File Preservation Rule

1. **No Rewriting / Overwriting Existing Markdown Files**:
   - Never overwrite or rewrite existing `.md` documentation or markdown files in the project.
2. **Create New Files**:
   - When new content, notes, summaries, logs, or documentation are required, always create a new `.md` file with a descriptive name (or versioned name/timestamp).
   - Keep existing markdown files completely untouched as immutable historical records and references.
